## PR作成手順

1. **issue内容を確認**: `gh issue view` コマンドでissueの詳細を取得
2. **必要な変更を実装**: issueの要求に従ってコードを変更
3. **変更をコミット**: `git add` と `git commit` でコミット
4. **PRを作成**: `gh pr create` コマンドで上記テンプレートに従ってPRを作成

## PRタイトル

PRタイトルは以下の形式で作成してください：
- 簡潔で具体的に（例：「背景色を赤から青に変更」）
- issueタイトルをベースにする

## PR本文の記載例

```markdown
## 概要
Issue #15 に対応し、Todoアプリの背景色を赤系から青系に変更しました。

## 変更内容
- `body`の背景グラデーションを青色に変更（#3b82f6, #2563eb）
- 追加ボタンの背景色を青色に変更
- input要素のフォーカス時のborder-colorを青色に変更
- チェックボックスのaccent-colorを青色に変更
- ボタンホバー時のbox-shadowの色を青色に調整

## 関連issue
Closes #15

## テスト方法
1. アプリを開いて、背景が青色のグラデーションになっていることを確認
2. 入力フォームをクリックして、ボーダーが青色になることを確認
3. 追加ボタンが青色になっていることを確認
4. タスクを追加して、チェックボックスが青色になることを確認

## チェックリスト
- [x] コードに日本語コメントを追加した
- [x] XSS対策を確認した
- [x] 既存機能に影響がないことを確認した
- [x] ローカルで動作確認を行った

---

```
