# create-pr - プルリクエストを作成

このcommandは、実装が完了した後にプルリクエストを作成します。

## 使い方

```bash
# GitHub Actions内で自動実行
claude /create-pr
```

## このcommandが行うこと

1. **変更内容の確認**
   - `git status` で変更されたファイルを確認
   - `git diff` で変更内容を確認

2. **PRタイトルの決定**
   - issueのタイトルをベースに簡潔なタイトルを作成

3. **PR本文の作成**
   - 以下のテンプレートに従ってPR本文を作成

4. **PRの作成**
   - `gh pr create` でPRを作成（base branch: main）

---

## PR本文テンプレート

以下のテンプレートに従ってPR本文を作成してください：

```markdown
## 概要

{このPRで何を実現するか、1-2文で簡潔に説明}

## 変更内容

{具体的な変更内容を箇条書きで記載}
- `style.css`: 背景色を赤系から青系に変更（#ef4444 → #3b82f6）
- `index.html`: {変更内容}
- `app.js`: {変更内容}

## 関連issue

Closes #{issue番号}

## テスト方法

{この変更をどのようにテストできるか記載}
1. アプリを開く
2. {具体的な操作手順}
3. {期待される結果}

## スクリーンショット（任意）

{UIの変更がある場合はスクリーンショットを追加}

## セキュリティチェック

- [x] XSS対策: textContentを使用
- [x] 入力バリデーション: 適切に処理
- [x] HTMLインジェクション対策: 実施済み

## チェックリスト

- [x] コードに日本語コメントを追加した
- [x] XSS対策を確認した
- [x] 既存機能に影響がないことを確認した
- [x] ローカルで動作確認を行った

---

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

## PRタイトルの形式

以下のような形式でタイトルを作成してください：

- ✅ **Good**: `背景色を赤から青に変更`
- ✅ **Good**: `Todoアイテムの削除機能を追加`
- ❌ **Bad**: `色の変更` （具体性が低い）
- ❌ **Bad**: `issue #15に対応` （内容が不明）

## コマンド例

```bash
# PR作成（HEREDOCを使用）
gh pr create --base main --title "背景色を赤から青に変更" --body "$(cat <<'EOF'
## 概要
Issue #15 に対応し、Todoアプリの背景色を赤系から青系に変更しました。

## 変更内容
- `style.css`: 背景グラデーションを青色に変更（#3b82f6, #2563eb）
- `style.css`: ボタンの背景色を青色に変更
- `style.css`: フォーカス時のボーダー色を青色に変更
- `style.css`: チェックボックスのアクセント色を青色に変更

## 関連issue
Closes #15

## テスト方法
1. アプリを開いて、背景が青色のグラデーションになっていることを確認
2. 入力フォームをクリックして、ボーダーが青色になることを確認
3. 追加ボタンが青色になっていることを確認

## セキュリティチェック
- [x] XSS対策: textContentを使用
- [x] 入力バリデーション: 適切に処理
- [x] HTMLインジェクション対策: 実施済み

## チェックリスト
- [x] コードに日本語コメントを追加した
- [x] XSS対策を確認した
- [x] 既存機能に影響がないことを確認した
- [x] ローカルで動作確認を行った

---
🤖 Generated with [Claude Code](https://claude.com/claude-code)
EOF
)"
```

## 実行前の確認

PRを作成する前に以下を確認してください：

1. ✅ すべての変更がコミットされているか
2. ✅ テストが通っているか（該当する場合）
3. ✅ セキュリティチェックが完了しているか
4. ✅ PR本文が適切に記載されているか
